# Documentation

## Produit (`docs/product/`)

- `vision.md` : vision, public, expérience, note IP
- `design-pillars.md` : piliers de conception
- `target-platforms.md` : plateformes, entrées, services Steam, matrice V1/V1.1/Future
- `non-goals.md` : hors périmètre

## Règles (`docs/rules/`)

- `rules-bible.md` : conventions, domaines, critères d'exhaustivité
- `glossary.md` : terminologie canonique
- `turn-structure.md`, `movement.md`, `combat.md`, `line-of-sight.md`, `equipment.md`, `abilities.md`, `objectives.md`, `victory.md`, `special-rules.md` : règles par domaine (`RULE-<DOMAINE>-NNN`)
- `open-questions.md` : ambiguïtés et interprétations
- `traceability.md` : index de traçabilité ; détail dans `traceability-<domaine>.md`

## Tickets (`docs/tickets/`)

- `README.md` : gabarit de ticket TH-NNN et liste initiale

## Conventions

- Contenu validé avec ArkType.
- Les documents de règles sont des reformulations techniques, pas une reproduction du texte officiel.
